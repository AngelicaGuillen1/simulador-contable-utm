Ejecutar el simulador en su computador

Requiere Python 3.11 o superior. Los comandos se ejecutan dentro de la carpeta descomprimida:

python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # macOS / Linux
pip install -r requirements.txt
python serve.py

Luego abra el navegador en http://127.0.0.1:5000. La primera vez tarda alrededor de un minuto porque genera la empresa simulada con su período contable.
